# Horn Resonance to Infernal Melody

**狩獵笛：波浪鼓（氣焰旋律）隨時派生 / 翻滾取消 / 無敵迴避 / 甩鬼火**

版本 **1.0**　｜　適用 Monster Hunter Rise: Sunbreak（Steam）

---

## 作者的話

本模組使用 **WorkBuddy AI（DeepSeek）** 開發。
可用 MOD 管理器安裝，或者直接把資料夾拖進遊戲根目錄；
前置需求跟使用方法請查閱本說明。

**這個模組做了什麼：**

1. 修復了原版遊戲中狩獵笛不能隨時派生波浪鼓（氣焰旋律）的問題，
   並且在原生波浪鼓動作中加入了兩個可以翻滾取消的點，讓他看起來更像冰原波浪鼓，
   動作中短按 ZL（L2 / LT）即可派生。
   這個波浪鼓能正常觸發氣焰旋律效果，也間接解決了氣焰旋律發動中使用者無法使用氣焰旋律的問題。
   當然，因為冰原狩獵笛波浪鼓無法接在演奏後面，所以這邊也禁止接在演奏後面。
2. 修復了原版遊戲中自我強化移速很慢的問題。
3. 修復了原版遊戲中鐵蟲絲響打明明是拉翔蟲動作，卻無法將鬼火留在原地的問題。
4. 修復了原版遊戲中奏模式下的演奏只有無敵判定，而不能觸發迴避效果的問題。
5. 給一些沒什麼用的招式增加了迴避判定：二連揮、揮舞連擊左右派生。
6. 三音演奏、震打、設置響玉等等長後搖動作，可以在動作開始後 180 幀派生波浪鼓取消；
   蟲技也可以派生波浪鼓取消，時機點如同原版接氣焰旋律的方法，只是按鈕不同。

如果遇到「動作還沒出來就派生波浪鼓取消」，可以勾選**自動學習取消點**重新抓一遍，
具體請見後面〈取消點自動學習〉。

## 安裝

把壓縮包裡的 `reframework` 資料夾（以及可選的 `natives` 資料夾）複製到**遊戲根目錄**，
選擇合併／覆蓋。

```
Monster Hunter Rise/
├─ MonsterHunterRise.exe
├─ dinput8.dll                            ← REFramework
├─ natives/                               ← 可選：自我強化移速
│  └─ stm/player/fsm/horn/
│     └─ horn.motfsm2.43
└─ reframework/
   ├─ data/                               ← 自動產生（設定與學習紀錄）
   └─ autorun/
      ├─ horn_resonance.lua
      └─ horn_resonance/
         ├─ core/
         └─ ui/
```

- **`natives` 是可選的**，只影響「自我強化移速」。
  不放的話其他功能全部照常，移速就是原版速度。
- 升級時請**整個 `horn_resonance` 資料夾覆蓋**，不要只挑有改的檔案。

## 使用方法

### 1. 波浪鼓派生（主要功能）

1. 拿**狩獵笛**進任務（不是狩獵笛時整個模組不會啟動）
2. 出**一般攻擊**（X / A / X+A 都算）
3. 攻擊動作**還沒回到待機**之前，**輕點 ZL / L2 / LT**（按住 0.25 秒以內放開）
4. 波浪鼓會接在「可以取消後搖的那一幀」

**不會觸發的情況（正常行為）**

| 情況                      | 原因                               |
| ------------------------- | ---------------------------------- |
| 站著不動時輕點 ZL         | 不在攻擊中，不會插隊               |
| 長按 ZL 超過 0.25 秒      | 判定為長按，不是輕點               |
| 按住 ZL 期間又按其他按鍵  | 判定為翔蟲技組合鍵，整組放行給遊戲 |
| 正在演奏                  | 演奏後不接波浪鼓（比照冰原）       |
| 接技冷卻中（預設 0.6 秒） | 避免連發                           |

**不會被動到的東西**

- **ZL+A 的共鳴音珠**：完全沒有攔截，行為跟原版一樣
- **翔蟲數量 / 回復時間**：沒有任何修改，完全交給遊戲（波浪鼓不消耗翔蟲）
- **翔蟲受身（ZL+B）**：剛被打到 1.2 秒內完全不接技；不是武器動作時也不搶按鍵

### 2. 波浪鼓翻滾取消

波浪鼓動作途中按 **B** 就能翻滾取消——跟冰原轉笛一樣。分兩段窗口：

| 動作進度        | 按 B 的結果                                                  |
| --------------- | ------------------------------------------------------------ |
| 前 30 幀        | 沒反應（戳地板還沒出來，滾掉沒意義）                         |
| **30 ～ 50 幀** | **緊急迴避**：立刻滾走。**放棄這一發**（沒傷害、沒 buff）    |
| 51 ～ 114 幀    | 沒反應（面板會提示「等 buff」）。音爆已打、buff 還沒生效，滾掉最虧 |
| **115 幀之後**  | **取消後搖**：buff 已生效，滾掉只少收招動作                  |

- 用的是遊戲自己的翻滾動作，所以**無敵幀、迴避判定、翔蟲派生全部原生**
- 115 幀是「旋律 buff 生效之後」，所以 **buff 一定吃得到**
- **四個方向都能滾**：往哪推左搖桿就往哪滾（前 / 後 / 左 / 右）；
  沒推搖桿就是往前滾
- 兩段窗口都可以在面板上單獨開關、單獨調起始／結束幀

### 3. 長後搖動作派生（180 幀後）

三音演奏、震打、設置響玉這類長後搖動作，**動作開始後 180 幀**（約 3 秒）就能派生波浪鼓取消。
蟲技也可以派生，時機點跟原版接氣焰旋律的方法一樣，只是按鈕不同。

> 如果發現「動作還沒出來就被派生掉了」，代表這個動作的取消點比 180 幀更早。
> 打開面板的**自動學習取消點**，正常打一場，模組會自己抓到你實際的派生時機。

### 4. 無敵幀與迴避判定（不用操作，自動生效）

| 招式                      | 效果                                                         |
| ------------------------- | ------------------------------------------------------------ |
| 五個常用攻擊動作（預設）  | 動作開頭 **30 幀無敵**，而且這幾幀會被算成「**迴避成功**」，迴避系技能會發動 |
| 奏模式的演奏              | 本來就有無敵判定，這裡補上「**迴避成功**」判定，所以迴避系技能真的會觸發 |
| 二連揮 / 揮舞連擊左右派生 | 補上迴避判定                                                 |
| 演奏（另一種）            | 本來就有原生無敵幀，只補「迴避判定」，**無敵長度完全不變**   |

- 無敵長度是綁**動作自己的動畫幀**，不受螢幕更新率影響
- 不需要任何額外按鍵；想關掉或換招式，見〈遊戲內面板〉

### 5. 甩掉鬼火（不用操作）

身上中了**鬼火やられ**的時候，做出**鐵蟲絲響打**就會自動甩掉，
鬼火會**留在你當時站的位置**，怪物走過去一樣會燒到。

- 原本只有部分翔蟲動作做得到，這版讓鐵蟲絲響打也能
- 身上沒有鬼火時**完全不會觸發**，不會憑空生出地上鬼火
- 每個動作只甩一次

> 演奏收尾**不用設定** —— 它本來就會甩鬼火（遊戲原生行為）。

### 6. 自我強化移速（需要 `natives`）

「自我強化」旋律的移動速度從原生的 +20% 提升到約 **+62%**（約原生的 1.35 倍），
連**起步的初速動作**也一起加快，所以起步不會頓。

沒放 `natives` 資料夾就是原版速度，其他功能不受影響。

### 7. 取消點自動學習

模組出廠時已經內建 **20 個動作**的實測取消點，新安裝第一次進遊戲就能用。

打開自動學習後，平常打怪就會自己學：

- 你自己玩到**更早**的取消點 → 自動收斂過去
- 打得不夠準也不會把取消點拉壞（合併規則取最小值，且有雜訊過濾）
- 按「清空個人學習資料」只清自己玩的紀錄，**內建值會保留**

> 自動學習**預設關閉**。內建值已經夠用，打開是為了補「內建沒有、但你常打」的動作。

## 遊戲內面板

進遊戲後按 **Insert**（或 REFramework 選單）→ **狩獵笛：L2 接技氣焰旋律**

| 面板                              | 用途                                                         |
| --------------------------------- | ------------------------------------------------------------ |
| **L2 輕點接技（氣焰旋律）**       | 總開關、輕點判定時間、接技冷卻、限定攻擊中、是否等取消點才接 |
| **迴避判定（無敵幀 / 迴避成功）** | 無敵幀開關、無敵幀數、迴避成功判定、要套用哪些招式           |
| **波浪鼓：戳地板後翻滾取消**      | 兩段窗口開關與幀數、翻滾方向開關、即時狀態                   |
| **甩掉鬼火**                      | 開關、觸發幀、手動測試按鈕                                   |
| **手動規則**                      | 禁止派生的招式、指定取消點的招式                             |
| **派生取消點學習**                | 自動學習、收集模式、輸出學習表、清空個人資料                 |
| **診斷**                          | 按鍵位元、動作狀態、日誌詳細度                               |

面板上會即時顯示「目前動作進度」「上一次按 B 落在哪個窗口」「最近結果」，
調幀數時照著那些數字拉最準。

## 常見問題

**Q：裝了但完全沒反應？**
A：先確認三件事——① `dinput8.dll` 在遊戲根目錄 ② `reframework/autorun/horn_resonance.lua` 存在
③ 手上是狩獵笛。都對的話開面板看「武器動作中」是不是 true。

**Q：輕點 ZL 一直變成翔蟲技？**
A：輕點時間調短一點（預設 0.25 秒），或確認按住 ZL 時沒有同時按其他鍵。

**Q：波浪鼓派生太慢 / 太早？**
A：把「等可以取消才接（不砍動畫）」關掉，就會立刻接；
想更貼近手感就用自動學習重新抓取消點。

**Q：翻滾只能往前？**
A：面板的「依左搖桿決定方向」要開著，而且按 B 的當下搖桿要推著。
四個方向指示都是空心圈代表沒讀到方向（會往前滾）。

**Q：演奏之後接不了波浪鼓？**
A：這是刻意設計的。冰原的波浪鼓不能接在演奏後面，這裡比照辦理。

**Q：移速沒變？**
A：`natives` 資料夾有沒有複製到遊戲根目錄？只放 `reframework` 不會有移速效果。

**Q：會影響其他武器嗎？**
A：不會。不是狩獵笛時整個模組不啟動，也不會搶按鍵。

**Q：多人連線會被踢嗎？**
A：本模組只修改「自己的」動作與按鍵判定，不修改怪物、傷害數值或連線封包。
但任何模組都有風險，請自行評估。

## 已知限制

- 翻滾方向是**角色相對**的：鏡頭被轉開、角色又沒轉向時，可能會覺得方向偏。
  這是因為遊戲本身也是用角色相對在選翻滾動作。
- 「緊急迴避」（30～50 幀）滾掉等於**放棄這一發**，沒有傷害也沒有 buff。
- 迴避成功判定是模組自己補的，所以理論上某些原本不可迴避的攻擊，
  在無敵窗口內也會被算成迴避成功。
- 演奏類動作的取消點只能用手動規則指定（玩家不會在演奏中途派生，學不到）。
